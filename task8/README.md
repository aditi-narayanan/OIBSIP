# Wireshark Network Traffic Capture and Analysis

## Overview

This project demonstrates network traffic capture using Wireshark, focusing on HTTP traffic generated by a browser (likely Mozilla Firefox) during startup.

## Tools Used

- **Wireshark** for packet capture and filtering

## Steps Followed

1. Installed Wireshark on a Linux VM.
2. Captured traffic on the local network.
3. Applied filters in Wireshark to isolate HTTP-related traffic ( using filter http or tcp.port==80 || udp.port==80 ).
4. Analyzed DNS queries, TCP handshakes, etc.

## TCP and Application Behavior

- Each HTTP request follows the standard pattern:
  1. **TCP 3-Way Handshake** (`SYN → SYN-ACK → ACK`)
  2. **HTTP GET Request**
  3. **HTTP Response** (200 OK or 404 Not Found)
  4. **ACK** to confirm response receipt

- **HTTP Content:**
  - HTML responses delivered in chunks and reassembled in Wireshark
  - CSS/JS static assets successfully retrieved
  - Headers and payloads appeared clean and complete
